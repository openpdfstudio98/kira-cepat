KIRA CEPAT

Dasar Privasi

Kira Cepat menyediakan kalkulator percuma dalam Bahasa Melayu dan Inggeris. Kalkulator boleh digunakan tanpa membuka akaun.

Input dan keputusan kalkulator

Input seperti gaji, jumlah pinjaman dan keputusan diproses dalam pelayar anda. Aplikasi tidak menghantar nilai tersebut ke pelayan. Jika anda memilih untuk menyalin atau berkongsi keputusan, kandungannya akan dimasukkan ke papan klip atau dihantar melalui aplikasi yang anda pilih.

Perkhidmatan pihak ketiga

Cloudflare mengehos laman ini. Untuk penukaran mata wang, pelayar meminta senarai kadar rujukan daripada ExchangeRate-API tanpa menghantar amaun yang anda masukkan. Halaman kalkulator juga boleh meminta fon daripada Google Fonts.

Analitik laman

Jika diaktifkan, Cloudflare Web Analytics mengukur trafik dan prestasi halaman seperti halaman dilawati dan masa pemuatan. Nilai input dan hasil kalkulator tidak disertakan dalam analitik. Maklumat lanjut tersedia dalam dasar privasi Cloudflare.

Pengiklanan

Laman ini belum menayangkan iklan. Dasar ini akan dikemas kini dengan penerangan tentang penyedia iklan, kuki dan pilihan privasi sebelum iklan diaktifkan.

Hubungi Kira Cepat

Untuk maklum balas, gunakan halaman isu GitHub Kira Cepat. Laporan di sana boleh dilihat umum. Elakkan menyertakan maklumat peribadi atau butiran gaji sebenar.
